## Slide 12：斜率與速度的關係

```
┌──────────────────────────────────────┐
│    速度怎麼算？How to find speed?      │
│                                      │
│             距離 Distance             │
│     速度 = ─────────────              │
│     Speed   時間 Time                 │
│                                      │
│    在走時圖上：                        │
│             1                        │
│     速度 = ─────                      │
│            斜率 Slope                 │
│                                      │

```

**小技巧**：用尺量角度，角度愈大愈陡愈快。

## Slide 17：折射 vs 反射

```
┌──────────────────────────────────────┐
│        折射            反射            │
│     Refraction      Reflection       │
│    ════════════    ════════════       │
│                                      │
│    波轉彎進下一層    波彈回來            │
│    Bends into       Bounces back      │
│    next layer                          │
│                                      │
│    可求地層「厚度」   可求地層「深度」     │
│    Layer thickness  Layer depth       │
│                                      │
│    工程地質常用      石油探勘最愛         │
│    Engineering      Oil exploration   │
└──────────────────────────────────────┘
```
